# Achraf Laifa | Professional Portfolio

Welcome to the repository for my personal portfolio website. This project showcases my skills, services, projects, and contact information through a modern, responsive, and highly interactive user interface.

## ✨ Features

- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.
- **Light & Dark Mode**: Seamless theme switching with a premium user interface and dynamic skill icons tailored for each theme.
- **Multilingual Support**: Built-in support for multiple languages (English & Arabic) including Right-to-Left (RTL) layout switching.
- **Premium Animations**: Features smooth scrolling, intersection-based fade-ins, dynamic progress bars in the "Tech Arsenal" section, and a custom sliding indicator in the navigation bar.
- **Dynamic Assets**: Automatically switches favicons based on the system's preferred color scheme.
- **Modern Tech Stack**: Built with high-performance tools and libraries.

## 🛠️ Technology Stack
Project is built with React, using Ant Design and font awesome.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173` (or the port specified in your terminal).

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/assets/`: Contains images, logos, skill icons, and other static media.
- `src/components/`: Reusable React components.
- `src/context/`: Application state management (Theme & Language context).
- `src/screens/`: Main sections of the portfolio (About, Services, Tech Arsenal, Projects, Contact).
- `src/styles/`: Global stylesheets and specific component styling.
- `src/translations.js`: Dictionary for English and Arabic text keys.
